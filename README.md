## 关于我 / About

我关注真实机器人系统从机械结构、PCB 与固件、运动控制、视觉感知到实机部署的完整链路。目前主要推进无人机挂载 Delta 机械臂、ROS 2 机器人系统和嵌入式软硬件项目。

I build real robotic systems across mechanical design, electronics, firmware, motion control, perception, and deployment. My current work focuses on a UAV-mounted Delta arm, ROS 2 systems, and embedded hardware/software integration.

## 代表项目 / Featured Project

### [78arm：无人机机械臂自主抓取](https://github.com/NHK-DOT/delta_on_quadrotorUAV)

**2026 嵌入式竞赛国二 · 项目队长**

- 设计无人机挂载三自由度 Delta 并联机械臂，覆盖结构设计、运动学建模、视觉感知部署、系统集成与实机调试。
- 使用 ArduPilot、STM32MP257、ROS 2、MAVROS 与 Jetson Xavier NX 构建飞控、任务决策和视觉推理解耦架构。
- 完成 UWB AoA 接近、YOLOv8/TensorRT 识别、AprilTag 定位、A* 路径规划、Delta FK/IK、轨迹插补与 LX-225 总线舵机控制链路。
- 基于 SolidWorks、碳纤维、CNC 6061、PA6CF/PLA 和自研 DC-DC/舵机驱动板完成多轮机械与硬件迭代。
